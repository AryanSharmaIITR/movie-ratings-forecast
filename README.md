# Movie Ratings Forecast

A collaborative filtering system built on the **Netflix Prize dataset** that predicts movie ratings and generates personalised recommendations.

---

## Project Structure

```
movie-ratings-forecast/
├── data/
│   ├── paths.py          # Centralised path definitions
│   ├── preprocess.py     # Raw file parsing, filtering, index mapping
│   └── split.py          # Train / test split logic
├── models/
│   ├── base.py           # BaseRecommender ABC + CSR utilities
│   ├── baseline.py       # Bias-only baseline (global mean + user/item biases)
│   ├── als.py            # Alternating Least Squares matrix factorisation
│   └── knn_cf.py         # Item-based KNN collaborative filtering
├── evaluation/
│   ├── metrics.py        # RMSE, MAE, MAP@K, NDCG@K, Precision/Recall, Coverage
│   └── evaluate.py       # Full evaluation pipeline (rating + ranking)

│   ├── train.py          # Train one or more models and save artifacts
│   └── recommend.py      # Load a saved model and generate recommendations for a user
├── NoteBook/
│   └── EDA.ipynb         # Exploratory data analysis
├── DataSet/
│   ├── combined_data_1.txt  # Raw Netflix rating files (not included in repo)
```

## Usage

### 1. Preprocess the raw data

Parses the Netflix rating files, filters to active users and popular movies, and saves processed parquet files.

```bash
python -m data.preprocess
```

Configuration is set directly in `data/preprocess.py`:

| Parameter | Default | Description |
|---|---|---|
| `min_user_ratings` | 50 | Minimum ratings a user must have to be included |
| `min_movie_ratings` | 2000 | Minimum ratings a movie must have to be included |
| `max_users` | 40 000 | Cap on number of users |
| `max_movies` | 1 500 | Cap on number of movies |

### 2. Train models

```bash
python -m script.train
```

Configuration is at the top of `script/train.py`:

| Variable | Default | Description |
|---|---|---|
| `MODELS_TO_TRAIN` | `["baseline", "als", "itemknn"]` | Which models to train |
| `TEST_FRAC` | `0.2` | Fraction of each user's ratings held out for testing |
| `K_VALUE` | `10` | Cutoff for ranking metrics (MAP@K, NDCG@K, …) |
| `QUICK_MODE` | `False` | Fewer epochs/iterations for fast debugging |

Trained models are saved as `.pkl` files in `results/Artifacts/`.

### 3. Get recommendations for a user

```bash
python -m script.recommend
```

Edit the configuration block at the top of `script/recommend.py`:

| Variable | Default | Description |
|---|---|---|
| `USER_ID` | `42` | Internal user index (0-based) |
| `USE_RAW_ID` | `False` | Set `True` to pass a raw Netflix customer ID instead |
| `MODEL_NAME` | `"svd"` | Model to use: `baseline`, `itemknn`, `als` |
| `K_RECOMMENDATIONS` | `10` | Number of recommendations to return |

## Models

### Baseline Bias
Predicts ratings as the sum of the global mean, a per-user bias, and a per-item bias, estimated with L2 regularisation. Serves as both a standalone model and the bias component inside ALS and ItemKNN.

### Alternating Least Squares (ALS)
Matrix factorisation on the residuals after subtracting the baseline biases. Alternates between solving for user factors and item factors in closed form, which is fast and avoids learning-rate tuning.

### Item-based KNN Collaborative Filtering
Computes cosine similarity between mean-centred item vectors, retains the top-K neighbours per item (sparse), then predicts ratings as a similarity-weighted average of residuals on top of the baseline.

## Evaluation

Every trained model is evaluated on:

| Metric | Type |
|---|---|
| RMSE, MAE | Rating prediction error |
| MAP@K | Ranking — average precision |
| NDCG@K | Ranking — normalised discounted cumulative gain |
| Precision@K, Recall@K | Ranking — relevance retrieval |
| HitRate@K | Fraction of users with at least one relevant hit |
| Coverage@K | Fraction of the catalogue recommended at least once |

A rating is considered **relevant** if it is ≥ 3.5 stars.
